# Galaxy Book Widgets

**Bring a touch of One UI to your Windows desktop.**

*Designed for Galaxy Books · Unofficial, independent Windows application*

Galaxy Book Widgets is a customizable desktop widget application for Windows 11, inspired by the clean design and fluid interactions of Samsung One UI. It brings useful information and everyday controls together in a cohesive desktop experience, with careful attention to visual consistency, smooth movement, and practical productivity.

## Features

- **Ten desktop widgets:** Clock, Calendar, Weather, Battery, Device Care, Digital Wellbeing (screen time), Music Player, News, Prayer Times, and Reminders.
- **One UI-inspired interface:** Rounded cards, coordinated icons, light and dark appearances, and customizable widget layouts.
- **Intuitive arrangement:** Drag-and-drop placement, directional snapping, animated widget swaps, adjustable spacing, and remembered positions.
- **Useful reminders:** Create and edit local tasks, connect Microsoft To Do, switch between local and synced views, and refresh manually or automatically.
- **Desktop integration:** Windows 11 context-menu access, startup support, and recovery behavior designed to keep widgets accessible after Show Desktop (Win+D).
- **Responsive interactions:** Smooth scrolling, subtle motion, and animated refresh controls, with attention to unnecessary background activity.

## Requirements and installation

- Windows 11
- .NET Framework 4.8 (required by the bundled source-build workflow)

To install from the supplied project archive, extract the complete package and run `Install_GalaxyBookWidgets.cmd`. The installer builds the application and installs it in:

`C:\Samsung\GalaxyBookWidgets\`

Widget preferences are maintained in the Windows user profile. Some features require internet access, a supported third-party service, or Microsoft account sign-in. The Windows 11 context-menu extension may require additional certificate trust or installation steps depending on the system.
